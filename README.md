# Tag Studio

A free rank tag maker for Minecraft servers. Design a pixel tag, download it as a transparent PNG, and copy the config for your plugin.

**Live site:** https://direkjames.github.io/tag-studio/

## What it does

- Type your rank name and pick a ready-made look, or style it yourself.
- Solid colors or gradients (with a random gradient button), borders, bevels, gloss and a shine streak.
- A pixel font built from the server's own tags, plus a slimmer one, with a pixel text shadow and outline.
- Garden decorations: flowers, vines, leaves and butterflies, or upload your own pixel sprite.
- Exports a PNG with a transparent background, at 1x for exact pixels or up to 16x.
- Config output for **Nexo**, **ItemsAdder** and **Oraxen**, with the ascent worked out so the tag lines up with chat text.
- Save tags to a library and export them all as one ZIP (PNGs + config).

Everything runs in your browser. Nothing is uploaded anywhere.

## Run it locally

It is a single static page. Open `index.html` in a browser, or serve the folder with any static file server.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole app (HTML, CSS and JavaScript). |
| `favicon.svg`, `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png` | Site icon and favicon. |

The ZIP export uses [JSZip](https://stuk.github.io/jszip/) from a CDN and the page uses the Inter font from Google Fonts.
